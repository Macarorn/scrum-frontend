🧪 CÓMO PROBAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣ LISTA DE USUARIOS
     • Navega a /proyecto/[id]/miembros
     • En tabla, columna "Rol" muestra badges con ⓘ
     • Haz clic en el ícono → aparece popover
     • Cierra con ESC o clic fuera
     
  2️⃣ NOTIFICACIONES
     • Navega a /notificaciones
     • Abre solicitud → botón "Aprobar"
     • Modal muestra selector de roles mejorado
     • Haz clic en ⓘ para ver info del rol
     
  3️⃣ PERFIL DE USUARIO
     • Navega a /perfil
     • Sección "Roles asignados" muestra pills
     • Haz clic en ⓘ para ver información
     
  4️⃣ RESPONSIVE
     • Redimensiona navegador (mobile, tablet, desktop)
     • Verifica que popover se adapta al espacio
     • Prueba en dispositivo móvil real


🎨 PERSONALIZACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Para agregar un rol:
  → Edita src/constants/scrumRoles.js
  
  Para cambiar colores:
  → Modifica scrumRoles.js (color, backgroundColor)
  
  Para cambiar estilos:
  → Edita RoleInfoPopover.css o RoleDisplay.css
  
  Para agregar más variantes:
  → Crea nueva clase en RoleDisplay.css
  → Agrega soporte en RoleDisplay.jsx
